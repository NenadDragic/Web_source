# Web_source

Website source/hosting files for my personal domains, backed up from the webhost. Each top-level folder is the document root for one domain:

- `ahlstrom-itsec.com` / `ahlstrom-itsec.dk` — ahlstrom-itsec site
- `coldicewarmblood.info` — coldicewarmblood.info site
- `dragic.com` — dragic.com site, including GPS/flight tracking pages (`fr24_dashboard.html`, `fr24_map.html`, `GPS_Status_Rapport.html`) and TFA weather station charts (`tfa/`)
- `taenkeboksen.dk` / `xn--tnkeboksen-d6a.dk` (punycode for tænkeboksen.dk) — tænkeboksen.dk site
- `public_html` — default/shared hosting root

This repo is a backup snapshot of the live hosted files, not a build source — there's no build step, just static HTML/CSS/assets as served.
